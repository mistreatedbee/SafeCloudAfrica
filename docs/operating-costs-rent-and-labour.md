# Safe Cloud Africa (IDSMP) — Operating “Rent” Costs + Implementation Labour

This document explains the **ongoing running costs (“rent”)** to keep the platform online, and why additional implementation work is billed separately (it’s real development labour required for a fully functional production system).

## 1) Monthly/annual “rent” (ongoing running costs)

These are **operating costs** required to keep the platform working in production (hosting, database, and backend services). They are paid **monthly/annually** and are separate from development fees.

- **Database rent**: **R90/month** for **12 months**
  - Total: **R1,080/year**

- **Backend rent** (choose one):
  - **Monthly plan**: **R360/month** (Total: **R4,320/year**)  
  - **Annual plan**: **R2,160/year** (paid once per year)

> Note: If you add paid services later (email delivery, SMS/WhatsApp, storage, domains), those providers may add additional usage-based costs.

## 2) What the implementation labour covers (why additional work costs more)

Building a real IDSMP platform is not “just pages”. To make it **secure, auditable, reliable, and scalable**, the work includes:

- **Backend development**: real services/APIs for every module
- **Database implementation**: schema design, migrations, data rules, and persistence
- **Security**: authentication, role-based access control, permissions per module, and audit logging
- **Storage**: secure uploads for documents, evidence, and certificates (with access control)
- **Notifications & automation**: email + in-app alerts, escalation rules, scheduled reminders
- **QA testing**: bug fixing, regression checks, stability testing
- **UAT support**: helping the client test/approve releases and addressing feedback
- **Production deployment & administration**: deployments, environment setup, monitoring, backups, maintenance

These items are required so the client ends up with a **fully functional platform** that can be used daily in real operations—without cutting corners or causing developer burnout.
