# Safe Cloud Africa (IDSMP) — Phase 1, Phase 2 & Phase 3 Scope + Pricing (Client Document)

## Context (what you have now)
This project is delivered in **3 phases** to keep scope controlled and to ensure each step is implemented properly.

Each phase is billed separately because moving from “working product” → “production-grade system” requires significant additional work: backend development, database implementation, security, storage, notifications, QA, UAT support, deployment, monitoring, and ongoing administration.

## Phase 1 (MVP Foundation) — Core system delivered

### What Phase 1 includes
- Full IDSMP UI and module structure (end‑to‑end flows)
- Initial dashboards and views for all modules
- Baseline data structures and stable data flows (initial content can be mock/sample)

### Why Phase 1 matters

## Phase 2 (Production MVP) — Real-time system implementation

### What will be implemented
**Platform foundation**
- Production authentication (login/logout, sessions, password policies, invites)
- Multi-tenant structure (Company → Site → Department)
- Role-based access control (Admin/Manager/Supervisor/Employee/Auditor)
- Database persistence for all modules (real records, not static/mock data)
- File storage for documents/evidence/certificates (secure access)
- Notifications (in-app + email) and escalation rules
- Search + filters (documents, incidents, tasks)
- Export reports (PDF/Excel) for audits and stakeholder reporting
- Audit trail (who changed what/when) for compliance defensibility

**Module MVP**
- Users & roles management (including contractor/visitor accounts as required)
- Tasks & time engine (expected vs actual, time entries, status automation)
- Planning/KPIs + feedback + acknowledgments
- Document Management (versions, approvals, review dates)
- Approvals/signatures (secure workflow and timestamping)
- Automated document review reminders + escalation
- Risk & hazard register (risk scoring + review triggers)
- Incidents + investigation templates + corrective actions (CAPA)
- Training matrix + records + certificate uploads + expiry reminders
- Audits/inspections + findings + evidence + CAPA linking
- Legal register + evidence + compliance status
- PPE issuing/returns/next issue date + cost tracking

### Why Phase 2 is required (value)
- **Production readiness**: real-time integration, real data storage, real users, secure access, reliable uptime
- **Compliance defensibility**: audit trail, evidence storage, approvals, traceability
- **Operational usefulness**: reminders, escalations, exports, search, permissions
- **Risk reduction**: prevents data loss, unauthorized access, and “spreadsheet chaos”

---

## Phase 3 (Full System) — Automation + Scoring + Scale (Paid Upgrade)

### What will be implemented
**Compliance scoring engine**
- Real-time compliance score (%), broken down by Documents/Training/Risks/Incidents/Audits
- ISO clause mapping (Annex SL structure) and drill-down dashboards
- Trend analysis + insights

**Automation & intelligence**
- Auto-create tasks from audit findings/incidents/overdue document reviews
- SLA escalation chains and management alerts
- Scheduled reporting (monthly packs) + auto-email delivery
- Optional AI positioning (risk scoring assistance, predictive trends, smart reminders)

**Sellable expansions**
- Behaviour-Based Safety (BBS): observations, reinforcement scoring, unsafe act trends, coaching workflow
- Contractors/Visitors: portals, inductions, sign-in, safety briefing sign-off
- Emergency preparedness: drills, plans, panic alerts, WhatsApp/SMS integrations (if feasible)
- Template library: industry packs, controlled “master files”, indexing for large file libraries

**Scale & commercial**
- External consultant workflows (restricted access, approvals, evidence review)
- Billing & plan management (per user/site/module), trials, invoices, upgrades
- Offline mode + sync (mobile-first) with conflict resolution (optional)
- Monitoring/observability (logs, metrics, alerts) and performance hardening

### Why Phase 3 is required (value)
- **Executives buy dashboards**: scoring + trends turns data into decision-making
- **Automation saves time**: fewer manual follow-ups, fewer non-conformances
- **Scalability**: supports multiple clients, different industries, consultants, and billing
